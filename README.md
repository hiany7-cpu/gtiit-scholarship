# GTIIT 广东以色列理工学院 — 本科生新生奖学金测算

🎓 广东以色列理工学院（GTIIT）本科生新生入学奖助学金智能测算工具

## 功能特性

- 支持 15 个省市高考排名一键匹配入学奖学金等级
- 自动识别创新潜质奖、学科特长奖、地区专项奖
- 兼得互斥规则自动优化，四年累计奖学金可视化
- 更新至 2026 年最新政策

## 技术栈

- React 18
- Vite 5
- Tailwind CSS 3
- lucide-react

## 本地开发

```bash
npm install
npm run dev
```

## 构建部署

```bash
npm run build
```
